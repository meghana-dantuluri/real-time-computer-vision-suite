\# Sign Language Recognition System



\## Overview

A machine learning application that recognizes selected static hand gestures and maps them to predefined words.



\## Features

\- Hand landmark detection using MediaPipe.

\- Training dataset collection through webcam.

\- Random Forest classification model.

\- Image upload and gesture prediction.

\- Real-time webcam recognition.

\- GUI developed using Tkinter.

\- Operating hours restricted to 6 PM–10 PM IST for recognition.



\## Supported Gestures

\- Hello – Open Palm

\- Stop – Closed Fist

\- Yes – Thumbs Up

\- No – Index Finger Point

\- Thank You – Peace Sign



\## Technologies

Python, OpenCV, MediaPipe, NumPy, Scikit-learn, Tkinter, Pillow and Joblib.
